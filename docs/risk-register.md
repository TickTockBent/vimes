# Risk register — external surfaces (Ranks)

Opened 2026-09-08 at the pivot (D1). Rule 0.6: every uncontrolled surface
gets an isolation plan; **verify**-rows are spikes, run before anything
is built on them; rule 0.7: rows are filled by observation, never by
documentation.

**Vimes rows stay live where the surface survives.** The archive's
[`vimes/risk-register.md`](vimes/risk-register.md) and V-spec §6 carry the
rows for the Agent SDK channel (vendored binary + version pins, `Options.env`
replaces the environment, `canUseTool` contracts, the plan-mode `~/.claude/plans/`
write, `ExitPlanMode` input drift, transitive MCP-SDK advisories), CLI
auto-update (V-D73 floor + last-verified pins), and system `git`. Those
surfaces are all still under the cut; their rows are referenced from here,
not copied, and a change to one is recorded **here** as a new row citing
the archive row it supersedes. Rows for the PTY channel, hooks-on-PTY,
ripgrep, the usage OAuth poller, and compaction hooks die with their
consumers at S1·0/S1·5.
